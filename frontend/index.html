Pay a team without publishing who's on it

Undisclosed is a payroll protocol on Midnight. An employer funds a pay run behind a single committed total. Each employee withdraws their own salary with a proof, not a name. The chain never learns who's employed or what anyone earns.

How a payroll run works

Four steps, all enforced by the Compact contract — no off-chain trust beyond the employer building the tree honestly.

01

Employer commits the payroll list

Off-chain, the employer hashes each employee's pubkey, salary, and a nonce into a commitment, builds a Merkle tree from them, and publishes only the tree's root and the total payroll amount.

02

Employer funds the shielded pool

The total payroll value moves into a shielded note. The chain sees a commitment and a value — never which employee gets what share of it.

03

Employee proves membership and withdraws

Each employee generates a zero-knowledge proof that they're in the tree, without revealing which leaf is theirs. A nullifier stops the same commitment from withdrawing twice.

04

Employer finalizes the run

Once withdrawals are done, the employer closes the run. No more proofs are accepted against it.

What the chain can and can't see

Public on-chain

  • Employer's pseudonymous pubkey
  • Merkle root of the payroll tree
  • Total committed payroll amount
  • Number of withdrawals (nullifier count)
  • When the run was finalized

Never on-chain

  • Which employees are in the payroll
  • Individual salary amounts
  • Which employee made which withdrawal
  • The employee-to-amount mapping
  • Whether a specific person is employed here
